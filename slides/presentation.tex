\begin{frame}{Постановка задачи}
\footnotesize
Исследуется взаимосвязь между параметрами моделей автокодировщиков и статистическими свойствами данных, на которых они обучались.

\begin{block}{Проблема}
Существующие подходы к анализу автокодировщиков основаны преимущественно на качестве реконструкции и скрытых представлениях. При этом упускается связь со статистической информацией о данных.
\end{block}

\begin{block}{Требования к веторному представлению}
\begin{enumerate}
    \item инвариантность относительно симметрий пространства параметров;
    \item сохранение статистических характеристик распределения обучающей выборки, в частности, структуры смеси распределения;
    \item линейная разделимость моделей, обученных на данных из различных распределений.
\end{enumerate}
\end{block}

\begin{block}{Задача}
Предложить метод отображения, основанный на спектральных характеристиках параметров автокодировщика, который формирует векторное представление, удовлетворяющее введенным ограничениям.
\end{block}
\end{frame}

%----------------------------------------------------------------------------------------------------------

\begin{frame}{Требования к представлению}

\begin{enumerate}
    \item Сохранение возможности разделения моделей, обученных на выборках, порождённых разными распределениями;
    \item Устойчивость к вариациям внутри одного распределения;
    \item Чувствительность к значимым статистическим различиям.
\end{enumerate}

\begin{frame}{Обозначения}
Пусть $p_c$ --- распределение данных класса $c\in\{1,2,\ldots\}$ на $\mathbb{R}^d$.

$\mathbf{X}_c = \{\mathbf{x}_i : \mathbf{x}_i \sim p_c\}_{i=1}^{n}$ --- выборка, порождённая распределением.

\bigskip

$\mathbf{f}_{\boldsymbol{\psi}}: \mathbb{R}^d \to \mathbb{R}^d$ --- модель автокодировщика с параметрами $\boldsymbol{\psi}$.

\bigskip

$\boldsymbol{\sigma}^{\text{model}} = \sigma_1^{\text{model}}, \dots, \sigma_m^{\text{model}}$ --- сингулярные числа матриц параметров модели $\mathbf{W}$.

$\boldsymbol{\sigma}^{\text{data}} = \sigma_1^{\text{data}}, \dots, \sigma_m^{\text{data}}$ --- сингулярные числа матриц данных.

\bigskip

Подмешивание $\tilde{\mathbf{X}}_{a|b} = [\mathbf{X}_a, \mathbf{X}_b] \in \mathbb{R}^{(n + n) \times d}$ --- конкатенация векторов из $\mathbf{X}_a$ и $\mathbf{X}_b$.
\end{frame}

%----------------------------------------------------------------------------------------------------------

\begin{frame}{Предложенный метод}
\begin{block}{Способ векторизации}
Использование сингулярных чисел матриц параметров как векторного представления модели:
\[
\boldsymbol{\sigma}^{\text{model}}(\boldsymbol{\psi}) = \text{CONCAT}(\boldsymbol{\sigma}_1^{\text{model}}(\mathbf{W}_1), \ldots, \boldsymbol{\sigma}_s^{\text{model}}(\mathbf{W}_s))
\]
\end{block}

\begin{block}{Алгоритм}
\begin{enumerate}
    \item Обучение автокодировщика (AE/VAE) на выборке;
    \item Извлечение матриц весов из всех слоёв модели;
    \item Вычисление сингулярных чисел для каждой матрицы весов;
    \item Конкатенация сингулярных чисел в единый вектор;
    \item Отбор первых $r$ сингулярных чисел.
\end{enumerate}
\end{block}
\end{frame}
%----------------------------------------------------------------------------------------------------------
\begin{frame}{Сингулярные числа выборок}
\begin{block}{Гипотеза}
Чем ближе векторы сингулярных чисел исходных выборок, тем хуже линейная разделимость векторов сингулярных чисел соответствующих им моделей.
\end{block}

\begin{block}{Лемма (Никитина, 2025)}
Пусть заданы матрицы данных $\mathbf{X}_1 \in \mathbb{R}^{n_1 \times d}$, $\mathbf{X}_2 \in \mathbb{R}^{n_2 \times d}$, $\mathbf{X}_3 \in \mathbb{R}^{m \times d}$. Тогда сингулярные числа матриц $\tilde{\mathbf{X}}_1, \tilde{\mathbf{X}}_2$, образованных подмешиванием векторов $\mathbf{X}_3$ к $\mathbf{X}_1$ и $\mathbf{X}_2$ соответственно, сближаются. То есть:
\[
|\sigma_i^{\text{data}}(\tilde{\mathbf{X}}_1) - \sigma_i^{\text{data}}(\tilde{\mathbf{X}}_2)| \longrightarrow 0 \quad \text{при } m \to \infty
\]
\noindent где $\sigma_i^{\text{data}}(\tilde{\mathbf{X}}_c)$ --- $i$-ое сингулярное число выборки $\tilde{\mathbf{X}}_c$, образованной подмешиванием векторов $\mathbf{X}_3$ к $\mathbf{X}_c$.
\end{block}
\end{frame}
%----------------------------------------------------------------------------------------------------------
\begin{frame}{Связь сингулярных чисел параметров модели с данными}
\begin{block}{Теорема (Никитина, 2025)}
 $\tilde{\mathbf{X}}_c = [\mathbf{X}_c, \mathbf{X}_3] \in \mathbb{R}^{(n+m) \times d}, ~~~ c \in \{1, 2\}$ --- новые выборки, сформированные подмешиванием.
 
\bigskip

На каждой выборке обучена модель линейного автокодировщика, минимизирующая функцию ошибки:
\[\min_{\boldsymbol{\psi}_c}(\mathcal{L}(\boldsymbol{\psi}_c)) = \min_{\boldsymbol{\psi}_c} \|\tilde{\mathbf{X}}_c - \tilde{\mathbf{X}}_c\mathbf{W}_{c}^{enc}\mathbf{W}_{c}^{dec\top}\|_F^2\]
\noindent с регуляризацией вида $\|\text{cov}(\mathbf{h}) - \mathbf{I}\|^2$, декоррелирующей векторы $\mathbf{h}$ из скрытого пространства, то есть $\text{cov}(\mathbf{h}) \sim I$.

\bigskip

Тогда средний квадрат разности между сингулярными числами параметров автокодировщиков:
\[
\|\sigma_i^{\text{model}}(\mathbf{W}^{enc}_1) - \sigma_i^{\text{model}}(\mathbf{W}^{enc}_2)\|_2 \underset{m \to \infty}{\longrightarrow} 0
\]
\end{block}
\end{frame}

\begin{frame}{Настройки вычислительного эксперимента}
\small

\begin{block}{Данные}
\begin{enumerate}
    \item CIFAR-10: 3 наиболее отличающихся класса;
    \item FashionMNIST: все 10 классов.
\end{enumerate}
\end{block}

\begin{block}{Модели}
\begin{enumerate}
    \item Автокодировщик и вариационный автокодировщик;
    \item Архитектура: 1-2 линейных слоя, скрытое пространство размерности 256.
\end{enumerate}
\end{block}

\begin{block}{Метрики}
\begin{enumerate}
    \item Accuracy, ROC AUC, Average Precision;
    \item Классификация: логистическая регрессия с $L_2$-регуляризацией;
    \item Статистика: среднее по 5 запускам с различными подвыборками.
\end{enumerate}
\end{block}

\begin{frame}{Выносится на защиту}
\begin{enumerate}
    \item Разработан метод векторизации моделей на основе сингулярных чисел параметров. Построенное таким образом векторное пространство обладает статистической информацией об обучающих выборках.
    \item Доказана теоретическая связь спектра параметров и данных для моделей автокодировщиков. Расстояние между векторами сингулярных чисел параметров моделей тем меньше, чем ближе распределения обучающих данных.
    \item В серии экспериментов проанализированы свойства векторных представлений моделей AE и VAE в зависимости от способа порождения обучающих данных. Экспериментально подтверждено утверждение теоремы.
\end{enumerate}
